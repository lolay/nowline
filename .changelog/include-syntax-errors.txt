```release-note:fixed
A lexer or parser error in an included file now fails the run, reported in that file at its line exactly as checking the file on its own reports it (CLI exit 1), in every include mode, `roadmap:ignore` included. Before, the parent rendered whatever the parser recovered and exited 0. The error also no longer surfaces as a misleading `start:` mismatch or "Cannot isolate" include error.
```
