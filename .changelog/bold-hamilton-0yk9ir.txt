```release-note:fixed
**MS Project and Mermaid exports: `after:` a `parallel` or a `group` now waits for its work to end.** The MS Project export wrote no link for an item or milestone `after:` a parallel, so MS Project started it on the project start; it now links to every track's task (an item, or a group's summary task), and MS Project starts it at the latest track end, the date the chart and the XLSX export give. The Mermaid export wrote the group or parallel id as is (`after g`), which Mermaid has no task for, so it started the task on the day the chart was viewed; it now names the tasks that end the container (`after fast s2 mid`). The MS Project export also writes a group that is a track of a parallel inside another group, which it used to drop. No bundled sample uses these shapes, so none of their exports changes.
```
