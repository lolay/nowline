```release-note:security
The MCP server's Streamable HTTP mode (`nowline --mcp --port`, `npx @nowline/mcp --port`) now creates a fresh server and transport for every request, so one HTTP client's messages can no longer reach another. `@modelcontextprotocol/server` moves to 2.3.1, which also stops a single in-limit request from exhausting server memory.
```
