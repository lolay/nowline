```release-note:fixed
**`@nowline/cli` + `@nowline/export` + `@nowline/config` — `-q, --quiet` now suppresses non-error stderr**: the help text promised it, but the flag only blocked `--verbose`. Under `-q` the CLI now drops `warning:` lines (variable-font substitution, `--strict` font fallback, renderer asset warnings under `--serve`), the MS Project lossy-feature summary, the `--mcp --port` listening banner, the `--serve --open` browser warning, and warning-severity diagnostics in the text report of a failing run. Errors, the exit code, and the `--diagnostic-format json` document (including `--dry-run --format=json`) are unchanged. `.nowlinerc` has no logging key: `NowlineRc.quiet`, which nothing read, is removed, and an rc `quiet` key is ignored like any unknown key. `@nowline/export` adds an optional `RenderInputs.onNotice` sink for non-fatal export notices; omitting it keeps the stderr default.
```
