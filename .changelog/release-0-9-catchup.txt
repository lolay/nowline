```release-note:changed
`@nowline/embed` is about 19 KB smaller (197 KB to 178 KB gzipped): the bundle no longer carries the language server's protocol layer, which a browser render never uses. Output is unchanged.
```

```release-note:fixed
The French `nowline(1)` page documents `--timezone`, matches the English `--now` entry and links `nowline(5)` again. In both languages the offset forms now read `±HH:MM` instead of `HH:MM`.
```

```release-note:added
`@nowline/core`'s `serializeToJson` takes an optional `SerializeOptions.uri`, written as the JSON's `file.uri` instead of the document's own URI.
```

```release-note:added
`@nowline/layout` exports `estimateTextWidth` and the measurement constants the renderer draws with (`capacityIconDxTerms`, `META_SUFFIX_DX_EM`, `WAVE_CELL_INSET_PX`, `WAVE_LABEL_HALO_INSET_Y_PX`, `WAVE_LABEL_HALO_PAD_PX`) and the `WaveHatchKind` type, now that layout does every measurement and the SVG renderer only draws.
```
