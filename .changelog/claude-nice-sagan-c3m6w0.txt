```release-note:added
**`@nowline/cli` — `nowline --mcp-install [<client>]` registers the MCP server with your agents**: one command writes the `nowline` MCP server into Claude Code, Claude Desktop, Cursor, VS Code, Codex CLI, Gemini CLI, Antigravity, Muse Code, OpenCode, GitHub Copilot CLI, Windsurf, Zed, Amp, or Goose; omit the client (or pass `all`) to install into every agent found on the machine. By default it registers the installed `nowline` binary by its stable PATH entry (Homebrew's `bin/nowline`, not the versioned Cellar path), so `brew install nowline && nowline --mcp-install` works without Node and keeps working across `brew upgrade`; `--server npx` registers `npx -y @nowline/mcp` instead. `--scope project` writes the config file in the current directory (`.mcp.json`, `.cursor/mcp.json`, `.vscode/mcp.json`, …) for committing, `--root <dir>` is baked into the registered command, `-n` previews the change, and `--mcp-uninstall` removes the entry. JSON and JSONC configs are edited in place with comments, other entries, indentation, and line endings intact; Claude Code's user scope and Codex go through their own `mcp add`, and Goose (YAML), or a harness whose CLI isn't on PATH, gets a snippet to paste. Re-running is safe. A client that fails is reported and the rest still install (exit 3); no agent found exits 2. The `nowline(1)` man page now also documents `--mcp`.
```
